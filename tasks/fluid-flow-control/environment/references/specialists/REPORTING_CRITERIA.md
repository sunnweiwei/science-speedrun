# 复现报告的尺度与判定方式

2026-09-07，根据用户要求：以后每个工况都要说明从什么起点改善到什么
程度、什么数值算比较好、什么证据足以支持复现。只列绝对分数或相对
论文残余值的倍数不够。本文件仅规定报告方式，不修改 benchmark、训练、
reward、资源集合或已发布的原始实验结果。

## 每个工况固定报告这些内容

| 起点与目标 | 我们的结果 | 如何解释 | 判定依据 |
| --- | --- | --- | --- |
| 无控制基线、论文结果及其来源/不确定性 | 独立评测均值、跨训练种子波动、checkpoint 与训练进度 | 相对无控制的改善、实现论文改进幅度的比例 | 本工况“较好”和“接近论文”的数值范围；复现/未达到/证据不足及原因 |

“起点”指同一评测协议下的无控制策略，不是任意随机初始化网络的分数。
全回合均值、后半程均值和瞬时终点值必须分别比较。论文中的无控制
验证表、训练曲线方差、单次测试曲线不能拼成一个假想的同口径基准。
使用历史结果时必须注明快照时间，不把旧 checkpoint 的分数写成新训练
的最新结果。默认保留主回报和物理指标，而不只挑好看的阻力值。

## 直观尺度：实现了论文多少改进

对于越低越好的同口径指标，令无控制值为 B、论文结果为 P、我们的结果
为 M，且 B > P：

- 相对无控制改善率：`(B - M) / B`（仅在 B 为正且比值有意义时使用）。
- 论文改善实现比例：`(B - M) / (B - P)`。
- 尚未实现的论文改善比例：`(M - P) / (B - P)`。

对于越高越好的原生回报，用 `(M - B) / (P - B)`。回报可为负，不能
直接用 `M / P` 表示能力比例。若论文改善量很小、被测量不确定性覆盖，
或目标统计口径不明确，则比例标为“不宜计算”，保留原始差异和原因。
不截断负改善或超过 100% 的值；超过 100% 本身不证明显著优于论文。

作为**组织方的解释性参考线，而非论文规定或自动验收标准**：

- 实现论文约 90% 的改善：效果已经比较好。
- 实现论文约 95% 的改善：接近论文性能，进入复现核验范围。

这样每个工况会得到不同的绝对数值参考线。低值更好的指标对应
`M <= B - 0.90 * (B - P)` 和 `M <= B - 0.95 * (B - P)`。
不能跨工况统一采用“差 0.1 就算成功”。这些线是在已看到部分实验
结果后提出的报告约定，不应称为事前注册的研究验收标准。

例子（仅演示算法，不是给当前 Pinball 补造同口径论文均值）：假设
B=2.9、P=.1、M=.25，则论文改善 96.6%，我们改善 91.4%，差 5.2 个
百分点；实现了论文 94.6% 的改善。90% 和 95% 的参考上限分别为 .38
和 .24。这比“我们的残余值是论文的 2.5 倍”更完整地表达差距。

## 什么情况下可以称为复现

达到上述解释线不自动等于复现。最终逐工况核验：

1. 工况、网格/重启、动作限制、时间跨度、指标和统计窗口能够对应；
   未恢复的设置明确标注。可称“性能接近的公开资源重建”，不冒充
   完全一致的原论文实验。
2. 完整训练后，对独立训练种子分别做冻结 checkpoint 评测，报告每个
   种子及均值、标准差/适当的不确定性。沿用阶段计划的三个训练种子；
   不以最佳种子、最佳瞬时值或不同预算混合平均替代复现结果。
3. 对主回报和关键物理指标给出**本工况**的合理容差及理由，并核验
   升力、控制代价和稳定性没有使“阻力接近”成为误导性结论。
   论文未公开的次指标只能报告本地结果，不编造论文容差或目标。
4. 区分实际性能差距与证据不足。误差区间重叠不等于统计等效；若种子
   波动或读图不确定性过大，应增加证据或标为待定，而不放宽区间来
   迁就结果。不能借“测量误差”掩盖求解器/重置偏差。

每个工况的具体复现容差在对应统计量有可靠依据后单独记录，解释其
与 90%/95% 参考线及不确定性的关系，不等看到最终分数后再挑范围。
目前旧表中的后段曲线视觉范围不是论文均值的误差条，不能取中点后
直接宣布上述比例或把范围转为正式验收阈值。缺依据时明确写“参考
范围，尚不能判定复现”，而不是硬给一个虚假的成功线。

原有 `paper-targets.json` 的未确认验收值和 `paper_match_accepted=false`
不因这一报告约定而改变。
