## Read-only monitoring

`episodes.jsonl`: completed training/evaluation episodes, phase and training-step
labels. `updates.jsonl`: actual optimization updates. `progress.json`: latest
periodic frozen-policy evaluation, available after the first 4,000 controls.
`policy-0000000.pt` is initialization, not evidence that learning has occurred.
Use checkpoint `actor_weight_delta_l2` to distinguish weight updates from BN buffers.

`completed.json` means the training budget ended. `workflow-completed.json` and
`independent-final/completed.json` confirm subsequent new-process evaluation;
the container should then exit 0. `independent-best/` is also evaluated when its
artifact file differs. The artifact SHA256 is recorded in the independent result.

Run `summarize_public.py --zero ZERO_DIRECTORY RUN_DIRECTORY...` to get raw and
physical metrics. It groups seed summaries only at the same evaluation budget.
Do not label intermediate initialized-policy metrics as trained performance.
