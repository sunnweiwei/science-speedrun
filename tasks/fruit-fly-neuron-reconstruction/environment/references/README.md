with paper/source versions and protocol boundaries. PATHFINDER-style modules
retain source citations in their docstrings. Operator-pinned dependency sources

shared SENSE proposals and two-node disjoint SHAPE merging. It does not reproduce
the paper's complete baseline, motifs, graph search, data split or score table.

not copied into the agent workspace.
