# Superseded evaluation artifacts

These files preserve an incomplete 32-date, eight-member, ten-day WN2
experiment. They use a different protocol and unequal date coverage across
seeds, so they must not be used as the current evaluation or to rank seeds.

The complete eight-date, 56-member, 15-day comparison of extended Seed 0,
original Seed 0, GenCast and simple references is in the
[final evaluation report](../results-summary/README.md).
