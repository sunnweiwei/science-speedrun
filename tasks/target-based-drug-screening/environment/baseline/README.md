# Reference implementations

Reference models are kept separate from the minimal task-contract starter:

- [drugclip/](drugclip/): paper-scale dual Uni-Mol DrugCLIP with fixed molecule
  initialization, ProFSA pocket pretraining and BioLiP fine-tuning.

These implementations use the same model-package and prediction contracts as
the minimal starter and are scored by `environment/evaluation/score.py`.
