# Research references

minimal-starter/ is a portable atom-histogram train/infer example, copied from
the repository's environment/starter. Its small MLPs show the interface and
streaming score format. Full-benchmark predictive quality has not been measured.

The scientific starting point is baseline/drugclip/. Its generic Uni-Mol
initialization is allowed; author benchmark-trained DrugCLIP checkpoints are
evaluator controls only and are not supplied or allowed for candidate training.
Use the available source code and architectural ideas freely within the
instruction and contract.
