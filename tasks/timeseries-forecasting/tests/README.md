# Tests

- `test.sh`: Harbor entry point; runs `main_verifier.py` on `/workspace/submission` with data at `/private/data` (the verifier overlay mounts `gifteval/` there; `/private` and `/tests` are root-only, so a package running as the runner uid can regenerate no label) and the split at `/tests/split.json` (`TIMESERIES_SPLIT_MANIFEST=/tests/split_smoke.json` for a plumbing run), writes `/logs/verifier/{report,reward,status}.json`, `results.csv` and `infer.log`. `reward.json` carries both `"score"` and `"reward"` equal to the primary SSI V3/V4 `7 domains -> 23 sources -> horizon` hierarchical log-ratio skill score.
- `main_verifier.py`: stages input/truth from the pinned data (both root-only: a call is given one cohort's copy under `work/cohorts/<c>/input`, never the whole split, whose later cohorts' contexts hold earlier cohorts' labels), runs the sealed package once per cutoff cohort inside a Bubblewrap namespace (`isolation.py`: runtime, package, input, output; no data, labels, workspace or network) under one timeout, each call with an empty `HOME`/`TMPDIR` that is removed afterwards. In uid mode every call then ends with `isolation.after_uid_call`: every runner-uid process is killed (a detached child would otherwise outlive its call), the call's output and home go back to root with mode 0700, everything the runner owns in the directories it can write (found once by a scan run as the runner) is removed, and so are its SysV IPC objects; so no call, the determinism rerun included, sees another's files, processes or outputs. The sealed package loses group/other write and set-id bits; `infer.log` is root-only and each call's output is copied into it as capped bytes. Merges the calls, reruns the smallest cohort for determinism under the same isolation, scores. Package output is read only from regular files whose `mean` and `quantiles` are plain datasets (`ts_io.open_package_h5`): an external or soft link, a virtual dataset (the review mapped one onto the labels and scored 0.999), external storage, a symlink or a FIFO is a failed config. A malformed package (wrong contract, a manifest that is not a JSON object, no `infer.sh`, declared pretrained assets, a symlink escaping the package) scores 0 with the violation named. `--phase stage|infer|score` splits it across processes for operators; the infer phase re-applies the root-only mode to the staged input and checks, in uid mode, that the runner cannot reach the data, the labels or the full input.
- `starter_and_reference_manifest.json`: locks exact model identities, parameter counts (`6.4M` official `B_19` starter vs `41.8M` scaled starter control vs excluded summary-only `50.9M` receipt vs `331M` same-context-cap `TimesFM-3` `F_single`), SHA-256 digests, V3/V4 hierarchical scores, and `flat_97_skill_diagnostic` values.
- `isolation.py`: the namespace (built without the network namespace where Docker refuses it, `status.json` says so; the container's `network_mode: none` keeps the package offline), and the fallback when no namespace works: with the verifier running as root the package runs as uid 10001 while the labels, `/private` and `/tests` stay root-only (`"uid"`); only with `TIMESERIES_ALLOW_NO_ISOLATION=1` does it run a plain child process, marked untrusted. `docker-compose.yaml` grants what namespaces the host allows (`security_opt`).
- `check_local_isolation.py`: runs a canary package through the verifier and asserts it saw no data, truth, workspace or network (`docs/validation/isolation_probe.json`).
- `Dockerfile`: verifier image (`pytorch/pytorch:2.14.0-cuda12.6-cudnn9-runtime`, PEP 668 override, the runtime pins under `constraints.txt`), with bubblewrap, the runner uid, the grader, the normalizer, both manifests and the bounds metadata baked in, and `/private` and `/tests` root-only. Built with the task directory as context (`docker-compose.yaml`).
- `docker-compose.yaml`: the Harbor overlay for the separate verifier: `main` built from `Dockerfile`, `${TASK_DATA_DIR}/gifteval` read-only at `/private/data/gifteval`, no network, the namespace grant, a healthcheck.
- Unit tests, pytest only (`bash run_unit_tests.sh`, about 15 s, no data or GPU; `unittest discover` finds nothing; as root the end-to-end tests open pytest's temporary tree to the runner uid themselves): `test_task.py` (protocol tables, the frozen manifest, masked seasonal error, hand-computed metrics, the zero-seasonal-error rule, quantile sorting, reward bounds), `test_verifier_failures.py` (missing / mis-shaped / NaN / unreadable predictions are model failures; malformed packages score 0; partial coverage; symlinks), `test_isolation.py` (the namespace hides planted labels, mode selection, the uid drop when root), `test_release.py`, `test_score_bounds.py`, `test_v4_hierarchical_parity.py`, `test_docs_scripts.py`.

Two notes for maintainers. The trusted grader is imported in process by `main_verifier.py` rather
than run as a separate `grader.py`: the submission is never imported, only executed through
`isolation.py` in its own namespace, and the verifier image bakes its own copy of `score.py`, so a
package cannot reach the scoring code. And the sealed copy dereferences symlinks, but only those that stay inside the package: a link that
escapes it (to the verifier's truth directory, to `/data`, anywhere on the host) is a rule violation
worth reward 0, because `copytree` would otherwise copy the target into the package. Packages
therefore carry their own `ts_io.py` rather than linking to `environment/evaluation/`, and a unit
test checks the copies have not drifted.

## Scientific & Literature Justification of Verifier Design

### 1. Primary Metric & Upstream Paper Provenance
- **Upstream Benchmark & Per-Configuration Metrics**: Directly adopts the 97-configuration evaluation suite (`23` canonical sources across `7` real-world domains, frequencies from `10S` to `A`, `short`/`medium`/`long` horizons, `326,490` test windows) and exact per-configuration point + probabilistic error definitions of **GIFT-Eval** (*Aksu et al., "GIFT-Eval: A Benchmark for General Time Series Forecasting Model Evaluation", arXiv:2410.10393, 2024*) and **GluonTS** (*Alexandrov et al., JMLR 2020*, `evaluate_model(..., axis=None, mask_invalid_label=True)`):
  - **MASE** of the median forecast $\hat{q}_{0.5}$ normalized by each instance's uncapped-history seasonal error (dropping zero-seasonal-error series identically to `numpy.ma` in `gluonts 0.15.1`, verified to $1.9 \times 10^{-7}$ across all 97 configurations in `docs/validation/golden_gluonts_full.json`);
  - **Mean Weighted Sum Quantile Loss (WQL / discrete CRPS)** averaged over the 9 decile levels $q \in \{0.1, \dots, 0.9\}$.
- **Hierarchical Skill Aggregation (`7 Domains -> 23 Sources -> Horizon`)**: Each configuration's `(MASE, WQL)` is divided by the pinned GIFT-Eval `Seasonal_Naive` reference (`seasonal_naive_reference.json`) and clipped to $[10^{-3}, 10.0]$ (with single-application log-space partial-coverage blending toward $10.0$ if wall-clock timeout truncated later cohorts). Because a flat geometric mean over all 97 rows weights multi-frequency, multi-horizon datasets (such as 8-configuration `electricity`, `solar`, `ett1`, `ett2`, or 7-configuration `jena_weather` and `loop_seattle`) up to $8\times$ as heavily as single-configuration healthcare or sales datasets (`hospital`, `covid_deaths`, `car_parts`, `restaurant`), SSI Benchmark V3/V4 aggregates log relative error $u_k = \frac{1}{2}(\log \tilde{r}_{\text{MASE},k} + \log \tilde{r}_{\text{WQL},k})$ hierarchically:
  1. Mean across frequencies within each `(domain, source, horizon)` cell;
  2. Equal mean across available horizons (`short`, `medium`, `long`) within each of the `23` sources;
  3. Equal mean across sources within each of the `7` domains (`Econ/Fin`, `Energy`, `Healthcare`, `Nature`, `Sales`, `Transport`, `Web/CloudOps`);
  4. $\text{signed\_score} = 1 - \exp(\overline{u}_{\text{domain}})$ and $\text{score} = \text{reward} = \operatorname{clip}(\text{signed\_score}, 0, 1)$, matching `harness/ssi_index_v3.py` (`forecast_rows` / `time_series`) to $< 10^{-12}$.
- **Same-Contract External Reference Alignment**: Following zero-shot foundation model protocols in **TimesFM** (*Das et al., ICML 2024*) and **Chronos** (*Ansari et al., TMLR 2024*), external references (`TimesFM-3` 331M at `0.4400`, `Chronos-2` 119M at `0.4161`) are scored via local replays under the exact same `16,384`-observation context cap and targets-only input contract (`starter_and_reference_manifest.json`) rather than mixing un-capped covariate-assisted public leaderboard CSVs.

### 2. Why Additional Ad-Hoc Constraints Are Intentionally Omitted
- **Monotone Quantile Rearrangement Instead of Disqualification on Quantile Crossing**: Following standard probabilistic forecasting practice (*Chernozhukov et al., Econometrica 2010*) and upstream foundation-model evaluation pipelines, non-monotone decile predictions are sorted along the quantile axis (`sort_quantiles`) before computing WQL rather than rejecting the submission; sorting weakly improves proper quantile loss and prevents brittle floating-point tie failures while `quantile_crossing_fraction` is logged diagnostically.
- **No Ad-Hoc Calibration Coverage Gate or Parameter-Count Penalty**: WQL over 9 deciles is already a strictly proper scoring rule jointly assessing sharpness and calibration; adding a separate empirical coverage gate (e.g., requiring 80% interval coverage within an arbitrary tolerance band) would reward artificially wide intervals and conflict with proper scoring theory. Likewise, inference efficiency is governed naturally by the single wall-clock cohort budget (`14,400 s`) with smooth log-space partial-coverage blending rather than arbitrary parameter-count or FLOPs penalties.
- **No Ad-Hoc Score Bounds Rescaling in `reward.json`**: `reward.json` emits the direct un-rescaled hierarchical skill `score` (`reward`) over Seasonal Naive so scores retain a fixed physical interpretation (`0` = Seasonal Naive parity, `1` = zero error) independent of external leaderboard snapshots.

### 3. Diagnostic Signals Retained in `report.json`
- **Legacy Flat-97 Leaderboard Skill (`flat_97_skill_diagnostic`, `flat_97_reward_diagnostic`, `rel_mase_gmean`, `rel_wql_gmean`)**: Exact flat 97-configuration geometric skill score retained for 1-to-1 comparison against historical GIFT-Eval leaderboard tables and `results.csv`.
- **Hierarchical Breakdowns (`domain_scores`, `source_scores`, `groups`)**: Per-domain (`7` domains) and per-source (`23` sources) hierarchical skill scores alongside geometric relative MASE/WQL breakdowns by `term` (`short`, `medium`, `long`), `domain`, `frequency`, and `variates` (`univariate` vs `multivariate`).
- **Probabilistic & Operational Diagnostics (`quantile_crossing_fraction_mean`, `n_partial`, `n_failed`, `failures`, `status.json["determinism"]`, `status.json["inference"]`)**: Per-configuration and mean quantile-crossing fractions, per-level weighted quantile losses (`wsql_by_level`), masked/zero-seasonal-error element counts, cohort-wise wall-clock runtimes, and bit-for-bit smallest-cohort determinism check results.
